# About
I really wanted to add more customization to my GitHub/ForgeJo profile, so I decided to make a Minecraft Text Generator for Profiles.  

# Try it out!
You can go to https://mcfont.com and create yourself one.

Here's an example:  
![MCFont.com](https://mcfont.com/view?scale=2&i=%26lHello%2C%26r%20%26o%26a%26gworld%0A%265O%26noo%26a%26ooo%26r%0A%26kSecret%20%26dtext)

# AI Usage
AI was used to help with font rendering & tab completes. 

# Setup
You must have Deno runtime installed, then you can do:
```
deno run start
```
The server will be active on `http://localhost:3000`!
